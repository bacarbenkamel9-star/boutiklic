# boutiklic
Boutiklic est une plateforme en ligne qui permet à chacun de créer sa propre boutique en ligne en quelques clics, avec l'aide de l'intelligence artificielle. Les vendeurs paient 2 € de frais d'ouverture puis un abonnement de 2 € par mois. Les clients achètent les produits des vendeurs directement sur leurs boutiques.
